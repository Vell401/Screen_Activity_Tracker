Screen Activity Tracker — установка браузерного расширения
===========================================================

Расширение передаёт URL и заголовок активной вкладки в приложение
Screen Activity Tracker по локальному адресу 127.0.0.1 (локальный HTTP-сервер
приложения). В интернет ничего не отправляется. Регистрация в реестре и
права администратора НЕ нужны.

УСТАНОВКА (Chrome / Edge / Brave / Yandex / Opera / Vivaldi)
-----------------------------------------------------------
1. Убедитесь, что приложение Screen Activity Tracker запущено.
2. Откройте страницу расширений:
     Chrome  → chrome://extensions
     Edge    → edge://extensions
     Brave   → brave://extensions
     Opera   → opera://extensions
     Yandex  → browser://extensions
3. Включите «Режим разработчика» (Developer mode) — переключатель.
4. Нажмите «Загрузить распакованное расширение» (Load unpacked).
5. Выберите ЭТУ папку (в которой лежит manifest.json).
6. Готово. На вкладке «Расширение» в приложении индикатор станет зелёным.

ПРОВЕРКА
--------
Откройте любой сайт — на вкладке «Расширение» появится «последний URL».
Если индикатор красный:
  • убедитесь, что приложение запущено;
  • обновите расширение (кнопка ⟳) или перезагрузите страницу расширений.

УДАЛЕНИЕ
--------
Просто удалите расширение со страницы расширений браузера.
